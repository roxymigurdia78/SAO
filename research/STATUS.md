## 1. いまの目標

光のループで「接地感（家具が床に乗っている感じ）」を扱えるようにする。
確かめる順番は「測れる → 直せる → 自然になる」。

| 段階 | 中身 | 状態 |
|---|---|---|
| 1. Unity の現状確認 | AO・影・ライトマップの設定を調べる | **完了**（10/14） |
| 2. 実写で測れるか | 写真から「家具の足元」と「周りの床」を取り出せるか（256画素で足りるか） | **未着手 ← 次はここ** |
| 3. 壊した部屋で感度確認 | 影を消した部屋（B）を、新しい物差しが拾えるか | 未着手（2 の後） |
| 4. つまみとの対応 | AO の強さ・広さ、影のぼけで、値と見た目がどう変わるか | 目で見る部分だけ済み（AO 0.4/1.1/1.5）。数値はまだ |
| 5. 人の判断と照合 | 数値の改善が、自然な接地感につながるか | 本人の目の判断のみ。正式な比較はまだ |

写真基準の接地評価が成り立たなかった場合の案:
「影の描画設定の確認」と「既存指標（L1〜L4・偏り）の限界」を成果として整理する。
GCF・NR-IQA は比較対象として記録するだけ（物差しにはしない）。

## 2. 決まったこと（10/14）

| 項目 | 決定 | 根拠 |
|---|---|---|
| ライトマップの細かさ | 12 → **80** | 12 は小物ににじみ。40→80 で細い縁がさらに改善。ベイク 22〜24秒 → 35秒 |
| AO の強さ（URP） | 0.4 → **1.1**（仮） | 本人が歩き比べ。0.4 は少し物足りない、1.5 は暗すぎて違和感。写真での裏付けは段階2〜5 |

## 3. わかったこと（実測）

- **光の種類で物差しが変わる**（P10〜P90）
  - 昼・自然光(73枚): 色温度 4824〜6577K、明るさ 0.249〜0.665、メリハリ 0.614〜1.423
  - 夜・暖色照明(85枚): 色温度 3631〜5973K、明るさ 0.199〜0.540、メリハリ 0.740〜1.468
  - 色温度の差は「GPT が見た目で暖色と判断した」ので半分は当然。明るさ・メリハリ・白飛びの差は本物
- **昼の物差しでループ**: 1.85 → 0.089 で止まった。色温度は 6500K でも届かない（木の床・家具が暖色）。
  太陽は 0.35 のまま（太陽を強くする手は 0.010 差で捨てられた）
- **今の物差しは「どこに光が当たるか」を見ていない**
  - 太陽を消しても（C）: 変化は写真の幅の約2%（中央値）、視点ごとでも最大約8%
  - 家具の影を消しても（B）: 目では分かる（椅子が浮く）が、L1〜L4 は拾えない
  - 3×3 などの偏り（最大÷最小）: 基準 0.2 で、B も C も 0 視点。
    理由 = 両端のマス（窓・暗い隅）しか見ていない／写真の幅が広すぎる／変化の面積が小さい
- **AO はよく効く**: 0.4→1.5 で 5〜7% の画素が変わる（今日試した中で最大）。
  弱いと浮く、強いと隅が黒い線になる → 「ちょうどいい値」があるつまみ

## 4. 見つかったが、まだ手を付けていないこと

- **影のぼけが未設定**（ベイクした影がくっきりしすぎ）。太陽は約0.5度、天井照明は器具の半径、と物理的な値で決められる
- **トーンマッピングがない**（撮影カメラにも exe にも）。明るい所は 1.0 で切られる。写真はカメラのトーンカーブを通っているので、物差しとの比較条件がずれている。光のループを回し直す前に決める
- 影の距離が 50m（部屋は 4m）、アンチエイリアス（MSAA）がオフ — 小さい問題
